Malayalam Typing — Ubuntu 22.04 layout

Click the box above, then type on your keyboard. Hold Shift for the upper layer shown on each key. Conjuncts (e.g. ക്ക, ന്ദ, ക്ഷ, ത്ര) form automatically when you type a consonant, then D (chandrakkala/virama), then the next consonant — just like the chart.

Quick reference — vowels & signs

Shifted key = independent vowel. Unshifted key = the matching vowel sign attached to a consonant. D alone is chandrakkala (്) — the virama used to build conjuncts.
